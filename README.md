# FOCZ — LOCK IN

A reversible, scroll-controlled product film and launch site, built with Vite, React, TypeScript, React Three Fiber, GSAP and Lenis.

## Run

```powershell
npm install
npm run dev
```

The configured dev port is 4173. Vite chooses another free port if that port is occupied.

```powershell
npm run build
npm run lint
npm test
```

## Experience

The film moves from metal macro photography through pressure and controlled release, then into snow, water, terrain and stillness. The single Tropical Punch can retains its identity throughout. Scroll in either direction, use the scene selector, skip to the product or replay the film. Audio is opt-in.

Geist Sans and Geist Mono use self-hosted Latin font subsets. The canvas uses a maximum DPR of 1.5, no antialiasing, demand rendering, instanced condensation and fixed environment maps. Lenis runs on the GSAP ticker. Reduced-motion preferences shorten the film and render held scene poses; a still-image edition appears if WebGL fails.

The outdoor film uses environmental crops of the campaign images; full campaign compositions remain in the asymmetrical gallery. Terrain fades into a longer, isolated LOCK IN hold before FOCZ and the closing actions. The launch list uses a warm bone panel, and the studio credit appears once in the film finale.

## Signup

The launch CTA opens the official drinkfocz.com signup. No email is collected or claimed to be saved by this project. Connecting an embedded form requires a confirmed mailing-list backend and the brand's form/privacy configuration. The giveaway copy reflects the official launch site; update it when the brand's launch offer changes.

The application has one FOCZ experience. The previous brand's runtime, catalogue, imagery, route components, fonts and contact details have been removed. Research and original architectural instructions remain as source documents.
